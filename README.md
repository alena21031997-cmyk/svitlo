# Світло? — графік відключень

Сайт (PWA) для GitHub Pages: графіки по чергах, погода по годинах, батарейка «світло за добу», історія оновлень.

## Запуск
1. Завантажте вміст цієї папки в репозиторій на GitHub.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. Settings → Actions → General → Workflow permissions → **Read and write permissions**.
4. Вкладка Actions → **Update outage data** → **Run workflow**. Далі робот оновлює дані кожні 15 хвилин.

## Оновлення
- Сторінка сама перевіряє дані кожні 15–20 хв, поки відкрита, і при поверненні на вкладку.
- Кнопка «Оновити» — ручна перевірка. Усі перевірки видно в «Історії оновлень».

## Пошук за адресою
Додаток шукає адресу у файлі `data/addresses.json` (якщо він є). Формат:

```json
{ "kyiv-region": { "м. Вишневе": { "вул. Шевченка": { "12": "2.2", "14": "3.1" } } },
  "kyiv":        { "м. Київ":    { "вул. Хрещатик":  { "1": "3.1" } } } }
```

Якщо файлу немає, працює ручний режим: введіть адресу, оберіть чергу (її видно на сайті оператора) і збережіть.

## Можливості
- Закріплена батарейка вгорі: світло за добу, перемикається «Сьогодні / Завтра» при гортанні.
- Графіки на сьогодні й завтра по годинах, температура, крапка поточного часу.
- «Світло за добу»: було / ще буде. Експорт у календар (`.ics`) і нагадування «за 30 / 15 хв» — у картці «Нагадування».
- Невеличка 3D-зірочка вгорі, коли світло з’являється чи зникає.
- Швидкі адреси (Дім / Робота), історія оновлень, офлайн-режим на https (`sw.js`).
- Картка «Слідкуйте за змінами»: сповіщення, коли графік вашої черги змінився, плюс нагадування перед відключенням. Кругла кнопка «вгору» при гортанні.
